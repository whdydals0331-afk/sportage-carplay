# 스포티지 드라이브 (sportage-carplay)

스포티지 QL(2015) + 파인드라이브 BF700 + 아이폰 17 Pro Max 조합을 위한
**카플레이 스타일 운전 모드 앱**입니다. 아이폰 홈 화면에 앱처럼 설치해서 거치대에 꽂아 씁니다.

## 먼저 알아둘 것 — 진짜 카플레이와의 차이

애플 카플레이는 **차의 화면(헤드유닛)이 카플레이를 지원해야** 나옵니다.
아이폰 앱을 만들어서 카플레이 미지원 화면에 카플레이를 띄우는 방법은 없습니다
(애플이 허용하지 않고, BF700 쪽 소프트웨어도 바꿀 수 없음).

BF700 이 카플레이를 지원한다는 공식 자료는 찾지 못했습니다. 그래서 이 앱은
**"BF700 화면 대신 아이폰 화면을 카플레이처럼 쓰는"** 방식입니다.

| 하고 싶은 것 | 이 앱 | 진짜 카플레이가 필요하면 |
|---|---|---|
| 큰 버튼으로 길안내 시작 | ✅ TMAP·카카오맵·네이버지도·Apple 지도 | 카플레이 지원 매립 내비/헤드유닛으로 교체 |
| 음악 → 차 스피커 | ✅ 아이폰 블루투스로 출력 | 〃 |
| 전화 | ✅ 단축 다이얼 + 블루투스 핸즈프리 | 〃 |
| 속도계·HUD | ✅ GPS 속도, 앞유리 반사용 반전 | — |
| 주차 위치 | ✅ | — |
| 소모품 교체 알림 | ✅ 스포티지 QL 기준 | — |

## 기능

- **카플레이식 홈** — 세로는 위 상태바, 가로(거치대)는 왼쪽 사이드바. 시계·현재 속도 상시 표시
- **길안내** — 즐겨찾기(집·회사 등 8개) 한 번 누르면 고른 내비 앱이 바로 안내 시작. 검색창도 있음
- **음악** — Apple Music / 멜론 / Spotify / YouTube Music 바로 열기
- **전화** — 단축 연락처 8개, 키패드
- **속도계** — GPS 속도·방향·최고·평균·주행거리. **HUD 반전**으로 밤에 앞유리에 비춰볼 수 있음
- **주차 위치** — 현재 위치 + 메모(예: 지하 2층 B-14) 저장, 걸어서 찾아가기
- **차량관리** — 주행거리 입력 → 엔진오일·필터·타이어 등 교체 시기 표시
- **화면 켜두기** — 운전 중 화면이 꺼지지 않게 (iOS 16.4 이상)
- **백업** — 설정을 복사해서 메모 앱에 보관, 폰 바꿀 때 붙여넣기
- 모든 데이터는 **아이폰 안에만** 저장 (서버 없음, 로그인 없음)

## 아이폰에 설치

1. 사파리로 배포 주소 접속 (아래 "배포" 참고)
2. 아래쪽 **공유 버튼(□↑) → 홈 화면에 추가**
3. 홈 화면의 **드라이브** 아이콘으로 실행 → 위치 권한 **허용**
4. **설정** 탭에서 집·회사·자주 가는 곳, 자주 거는 번호 등록

### 차에 타면 자동으로 열리게 (iOS 단축어)

1. **단축어** 앱 → **자동화** → **새로운 자동화** → **블루투스**
2. 차 블루투스(BF700 또는 차량 핸즈프리 이름) 선택 → **연결될 때** → **즉시 실행**
3. 동작: **URL 열기** → `배포주소/?go=home`
   - 바로 집으로 안내 시작: `배포주소/?dest=집` (설정에 등록한 이름과 똑같이)

### 운전 중 팁

- 화면 위를 누르기보다 **"Siri야, 집으로 안내해줘" / "Siri야, 아내에게 전화해"** 가 더 안전합니다
- 화면이 꺼지면 아이폰 **설정 > 디스플레이 및 밝기 > 자동 잠금 > 안 함** (운전 후 되돌리기)
- 속도계는 GPS 기준이라 계기판보다 몇 km/h 낮게 나오는 게 정상입니다 (계기판이 보통 조금 높게 표시)

## 배포 (GitHub Pages, 무료)

이 저장소에는 `main` 에 올리면 자동으로 GitHub Pages 에 배포하는 설정
(`.github/workflows/pages.yml`)이 들어 있습니다.

1. 저장소 **Settings → Pages → Build and deployment → Source: GitHub Actions**
2. `main` 에 push → Actions 탭에서 초록 체크 확인
3. 주소: `https://<깃허브아이디>.github.io/sportage-carplay/`

> 무료 GitHub 계정에서 Pages 는 **공개(public) 저장소**에서만 됩니다.
> 이 코드에는 개인정보가 없습니다 (목적지·연락처는 각자 아이폰에만 저장).

## 개발

빌드 도구 없는 순수 HTML/CSS/JS 입니다.

```
python3 -m http.server 8000   # http://localhost:8000
npm test                      # node --test (딥링크·GPS 잡음 필터·소모품 계산·저장값 정리)
```

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `styles.css` | 카플레이풍 다크 테마, 세로/가로 레이아웃 |
| `app.js` | 화면 전환·GPS·저장 |
| `lib.js` | 순수 계산 (딥링크, 거리, 소모품, 저장값 정리) — 테스트 대상 |
| `sw.js` | 앱 껍데기 오프라인 캐시 |

길안내·음악은 각 앱으로 넘겨주는 방식이라 **해당 앱이 아이폰에 설치되어 있어야** 합니다.
설치 안 된 앱을 고르면 아무 일도 안 일어나니, 쓰는 내비 앱을 골라두세요.
